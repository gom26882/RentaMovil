# RentaMovil

Proyecto desarrollado para el curso **Programación Orientada a Objetos**, Universidad del Valle de Guatemala

RentaMovil es una aplicación de consola en Java para administrar el alquiler de automóviles, motocicletas y camionetas de carga.

## Funcionalidades

El programa permite:

- Registrar nuevos vehículos.
- Mostrar los vehículos registrados.
- Cotizar el alquiler de un vehículo.
- Confirmar un alquiler.
- Registrar la devolución de un vehículo.
- Consultar la disponibilidad de la flota.
- Mostrar los ingresos acumulados.
- Generar un reporte general.

## Requisitos

Para compilar y ejecutar el proyecto se necesita:

- Java JDK 17 o superior
- Una terminal o un IDE compatible con Java, como IntelliJ IDEA, Eclipse o VS Code

## Compilación

Desde la carpeta raíz del proyecto:

```bash
javac -d out src/constants/*.java src/model/*.java src/view/*.java src/controller/*.java src/Main.java

```
o selecciona el botón ejecutar en VS Coda con la clase main seleccionada.
